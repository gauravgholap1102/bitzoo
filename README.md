# Bitezzo Foods & Beverage 🍔🍹
> **"Good Foods, Great Vibes"**

Premium, modern food ordering web application built for Bitezzo Cafe.

## 🚀 Built With
- **React.js**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**

## 📦 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
